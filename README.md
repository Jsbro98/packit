# PackIt

PackIt is a real-time chat application built collaboratively.

## Goals

- Learn and practice collaborative software development
- Explore networking and concurrency
- Build a layered Java application
- Practice professional Git workflows

## Tech Stack

### Backend

- Java
- Spring Boot
- WebSockets

### Frontend

- Vite
- TypeScript

## Architecture

Frontend → Spring Boot → Chat Engine → Networking Layer

## Running the Project

### Backend

```bash
./mvnw spring-boot:run
