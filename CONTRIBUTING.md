# Contributing

## Branches

- `main` = stable
- `dev` = active development
- `feature/*` = feature branches

## Workflow

1. Branch from `dev`
2. Make changes
3. Open PR into `dev`
4. Review before merge

## Commit Style

Examples:

- `feat: add websocket endpoint`
- `fix: repair message broadcast`
- `docs: update README`

## General Guidelines

- Keep PRs focused
- Discuss large changes first
- Write clear commit messages
